
# 2) Stream UI Design (No Inbox Guilt)

Now let’s design the UI so it **cannot psychologically collapse into an inbox**.

This is subtle but critical.

---

## First Rule: Never Call It an Inbox

Language matters.

Use:

- **Stream**
    
- **History**
    
- **Timeline**
    

Never:

- Inbox
    
- Saved items
    
- Tasks
    
- Library
    

---

## Overall Layout

```
[ Leo ]

Recently Relevant
• Item A
• Item B
• Item C

──────────────

Earlier
• Item D
• Item E
• Item F
• Item G
```

Key idea:

> The past gently recedes.

---

## Section 1: Recently Relevant (Working Set)

### Visual Treatment

- Soft background
    
- Slight blur or lighter contrast
    
- Feels _current_, not important
    

### Rules

- Max 7 items
    
- Auto-curated
    
- No controls
    
- No “why am I seeing this?”
    

This should feel like:

> “Things still floating in your head”

Not:

> “Things you must act on”

---

## Section 2: The Stream (Chronological)

### Visual Rules

- No hard separators
    
- No pagination
    
- No numbers
    
- No counts (“You have 312 items” is forbidden)
    

Older items:

- Smaller text
    
- Less contrast
    
- More whitespace
    

The UI should visually say:

> “The past is allowed to fade.”

---

## Item Design (Extremely Important)

Each item should look like:

- A memory fragment
    
- Not a note
    
- Not a task
    
- Not a card
    

### Item contains:

- Content
    
- Subtle timestamp (“2 days ago”, not exact times)
    
- Source hint (Telegram / Web / Extension)
    

### Item explicitly does NOT contain:

- Checkboxes
    
- Action buttons
    
- Edit icons
    
- “Mark as read”
    
- Star / pin / favorite
    

If an item looks actionable, guilt will follow.

---

## Search UI (Reframed)

### Placeholder text

Not:

> “Search your saved items”

Instead:

> **“What are you thinking about?”**

This reframes search as **reflection**, not retrieval.

---

## Search Results Behavior (V1 Recall Moment)

When searching:

Top section:

> “You’ve seen things like this before”

2–3 resurfaced items.

Below:  
Filtered stream.

This teaches users:

> Searching is not about precision.  
> It’s about remembering.

---

## Empty States (Critical)

### Empty Stream (new user)

Not:

> “Start saving things”

Instead:

> “Leo remembers quietly.  
> There’s nothing here yet.”

No CTA urgency.

---

### Empty Search Results

Not:

> “No results found”

Instead:

> “Nothing like this has crossed your attention yet.”

This avoids failure framing.

---

## What You Must Never Add to the Stream UI

These will instantly destroy the category:

❌ “Clear inbox”  
❌ “Unread”  
❌ “Mark as processed”  
❌ Item counts  
❌ Progress indicators  
❌ Productivity language

---

## The UI Gut Check

Ask this question:

> “If I don’t open Leo for two weeks, does this UI make me feel behind?”

If the answer is **yes**, the UI is wrong.

The correct feeling is:

> “Nothing broke.”
