# Leo Desktop - Sprint 5: Packaging

## Task
Package the application into a distributable `.dmg` file for macOS. This allows the user to drag-and-drop the app into Applications and run it on other machines.

## Completion Criteria
- [ ] Configure `electron-forge` makers for macOS (ZIP and DMG if possible, or just ZIP/Squirrel).
- [ ] Ensure the application icon is correctly applied in the build.
- [ ] Run `npm run make`.
- [ ] Verify the output in `out/make`.
- [ ] (Optional) Verify the built app runs standalone.

## Max Iterations
5
