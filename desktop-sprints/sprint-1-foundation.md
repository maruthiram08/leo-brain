# Leo Desktop - Sprint 1: Foundation

## Task
Initialize the Electron project foundation. This sprint focuses purely on getting a "Hello World" Electron app running that sits in the system tray, without any complex logic yet.

## Completion Criteria
- [ ] Initialize `desktop-app` directory with `electron-forge` (simpler than create-electron-app for now).
- [ ] Configure `tsconfig.json` for TypeScript support.
- [ ] Verify the app launches and opens a window.
- [ ] Implement a basic System Tray icon (even a placeholder).
- [ ] Verify the app can be quit from the tray.
- [ ] Ensure `npm start` works reliably.

## Max Iterations
10
